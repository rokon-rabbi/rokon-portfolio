The full Node command uses `--test-isolation=none`, as required by the repository's existing test setup. After the full suite, the SSH test was additionally rerun with `ssh -G` to verify **effective OpenSSH settings**, not just configuration text: strict host checking, batch/key-only access, correct host/port, no agent forwarding and 0600 identity permissions. All SSH keys were generated locally and discarded; no `ssh` session or `rsync` transfer contacted a VPS.

The first sandbox browser invocation could not bind the loopback port (`EPERM`). The same local-only command was rerun with approved browser/server permissions and produced the passing result above. This permission adjustment did not authorize production access.

Artifact tests reject changed bytes, missing outputs, extra/private entries, symlinks, modified sidecars and wrong SHA/run/attempt/domain before rendering configuration. Transport tests reject disabled approval, PR/feature-branch events, mismatched commits, root SSH, unsafe host/path/release values, wildcard/wrong-host known-hosts lines and mismatched SHA256 fingerprints. Retention tests prove that dry runs are read-only, recently used releases survive the grace period, archives are verified/private, current/previous and shared assets survive pruning/rollback, and unknown/corrupted release entries stop deletion. Unrelated administrator files remain untouched.

The Playwright production suite checks all 11 route types in both themes at **320, 375, 390, 768, 1024, 1440, 1920 and 2560 pixels**, plus navigation, menu focus, theme persistence, gallery hydration, motion/reduced-motion, WebGL fallback/lifecycle, JavaScript-disabled baseline, internal links and resume downloads. Its 12 skips cover nine fixture-only publication/media checks, two desktop-project touch checks and one Firefox-specific WebGL lifecycle exclusion. They are reported as skips, not passes. Full fixture checks remain in the separately documented responsive QA. CI screenshots/traces use ignored `test-results/responsive/`; the JSON result is [ci-playwright-results.json](../responsive-qa/ci-playwright-results.json).

The rendered desktop Home screenshot (1440px/light) and mobile About screenshot (390px/dark) were also visually inspected. Their navigation, typography and composition remain balanced; no application layout changes were needed for this workflow work.

The current [GitHub concurrency documentation](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency) explicitly supports `queue: max` for up to 100 pending operations. The latest [actionlint release](https://github.com/rhysd/actionlint/releases/tag/v1.7.12) does not recognize that key. The exact diagnostic exclusion is documented in [the CI/CD guide](../../deploy/CI-CD.md); all remaining syntax/expression checks were run. ShellCheck is not installed locally, so it was explicitly disabled in actionlint; separate `bash -n` checks passed. GitHub's own workflow execution remains untested until these files are pushed.

The build retains existing Astro CSP attribute-scope notices and a Vite warning for the optional Three.js chunk. Bundle analysis measures that deferred scene at **525.8 KiB minified / 130.2 KiB gzip**; it remains dynamically loaded. No new browser code or runtime dependencies were introduced. This pass does not claim new Lighthouse or field Core Web Vitals measurements.
